# gowest 原生程序

只分发本目录：可执行文件 `gowest`、此说明、第三方许可、版本信息、校验文件。不含 gowest 的 Python、Shell、PowerShell 源码。编译提高直接阅读的门槛，不保证无法逆向；配置文件和协议参数仍可被使用者查看。

先查看 `build-info.json` 的平台与架构：Linux 包仅用于对应架构的 Ubuntu 24.04；Darwin 包只在 Mac 准备参数、离线生成配置，不能部署 Linux。不要将 Mac 二进制上传到 Linux。

## Linux 新机部署

要求空白 Ubuntu 24.04、systemd、公网 IPv4、至少 512 MiB。无需安装 Python/PyYAML，程序内含运行时；仍需联网下载 APT 依赖和 sing-box。已有代理、Nginx 或所需端口占用会停止，不支持强制覆盖或原地升级。

先用 `sha256sum -c SHA256SUMS` 校验文件。进入目录，在 tmux 会话中运行（原生版尚未实测断线行为，务必使用 tmux）：

```sh
sudo ./gowest
```

按向导填一次带宽（`30Mbps`、`1Gbps`），公网 IP 自动识别并请你核对。订阅默认 HTTP，无需域名证书；输入 `HTTP` 确认明文传输节点凭据的风险。HTTPS/双入口可选，需自行提供证书。电脑、Android、iOS 配置全部生成。最后输入 `INSTALL` 才开始安装。

不要为了方便开启所有端口。本机 UFW 仅在安全范围内新增 TCP/UDP 443 和订阅端口；不清空规则、不改 SSH、不启停防火墙。云安全组没有自动操作集成，必须在云控制台确认 TCP 443、UDP 443、TCP 80（HTTP 默认）入站允许。冲突、未知策略或权限不足会明确提示。

安装显示八个阶段，长步骤每 15 秒显示仍在运行。持久日志仅 root 可读：

```sh
sudo tail -f /var/lib/la-vpn-deploy/install.log
sudo /opt/la-vpn/gowest status
sudo /opt/la-vpn/gowest verify
sudo /opt/la-vpn/gowest urls
```

`urls` 单独显示私有链接和各端说明，不要转发这段输出或截图。电脑/Android 共用普通与严格 YAML，iOS 小火箭使用节点订阅及两份 `.conf`。选择导入相应配置；不会自动控制手机、安装付费应用或切换现有订阅。

命令错误摘要在 `/var/lib/la-vpn-deploy/command-errors.log`。日志做常见凭据脱敏，但仍应仅给可信人员。失败会尝试回滚并报告归档路径，日志、密钥和配置一起保留；依赖包及服务账户不会清除。预检拒绝时未创建部署目录，错误只显示在终端。

“本机安装完成”不表示公网可达，仍需外部客户端检查订阅下载及 TCP/UDP 通路。打包时的离线自检也不是空白服务器全流程验收，实际测试范围见 `build-info.json`。

## 离线准备

以下示例中的 IP 必须替换成目标服务器公网 IP。`init` 仅保存参数，`render` 仅生成全新私有目录，不发布或安装服务。

```sh
./gowest init --server-ip 你的公网IP --bandwidth 30Mbps --accept-http-risk
./gowest plan --settings settings.local.json
./gowest render --settings settings.local.json --output generated-review
```

macOS 首次运行可能受系统安全策略限制：仅在确认来源和校验值后由本人允许打开；程序没有 Apple 公证。包内不含原项目的桌面自动安装脚本；现有 Clash 导入及手机配置按 `urls` 输出操作。

Mac 的 `init / plan` 不需要另装 Python；`render` 生成密钥需要 PATH 中有 OpenSSL 3 命令行程序。内置 LibreSSL 可能不支持所需的 X25519 命令，编译包内的 TLS 动态库不能替代命令行程序。已安装 Homebrew OpenSSL 3 时可执行 `export PATH="/opt/homebrew/opt/openssl@3/bin:$PATH"` 后再生成。工具不会擅自安装 Homebrew、修改系统路径或客户端配置。
