# DC 代理使用指南

看 YouTube · 刷 TikTok · 用 Claude / Claude Code

适用：Clash Verge / Mihomo，配置版本 0.5.0 · 2026-10-26。
本文只使用 DC 订阅。日常推荐场景 2；主要用网页可选场景 3。

## 先认清两份订阅

- **DC · 日常分流**：YouTube、TikTok、Claude 等走代理；命中国内规则的连接直连。
- **DC · 全公网代理**：普通公网连接都走代理，国内也不再直连；规则模式保留必要的私网 / Tailscale 例外。

一次启用一份订阅。「全公网代理」是原严格版，订阅链接末尾为 `-us`。

## 1. YouTube、TikTok、Claude，连国内网站 / 应用也一起走代理

适合：希望国内、国外的普通公网连接都通过 DC 服务器。

- **订阅**：DC · 全公网代理
- **出站模式**：全局
- **系统代理**：开启
- **TUN**：开启
- **代理组**：GLOBAL → 自动回退

全局模式下，不需要分别设置 YouTube、TikTok、Claude 组；被接管的普通连接统一按 GLOBAL 出站。GLOBAL 通常在切到全局模式后显示。

必要的路由例外仍存在。若需要按分流规则保留局域网 / 管理连接，改用场景 4。

## 2. 看 YouTube、刷 TikTok、用 Claude；国内网站 / 应用直连（日常推荐）

适合：浏览器和本地应用都需要分流，国内连接不绕海外。

- **订阅**：DC · 日常分流
- **出站模式**：规则
- **系统代理**：开启
- **TUN**：开启
- **代理组**：出口选择 / AI / YouTube / TikTok → 自动回退；Claude → AI

TUN 接管连接后，命中国内规则的仍然直连，不经过 DC。这里的「国内不受影响」指保留直连，并非完全绕过 Clash；规则分类也可能有误差。

其他未分类公网连接仍走兜底代理，不是只有这三个网站走代理。

## 3. 主要看 YouTube / TikTok 网页版、用 Claude 网页版；不开 TUN

适合：主要用遵循系统代理的浏览器，不要求整机应用接管。

- **订阅**：DC · 日常分流
- **出站模式**：规则
- **系统代理**：开启
- **TUN**：关闭
- **代理组**：出口选择 / AI / YouTube / TikTok → 自动回退；Claude → AI

系统代理不是浏览器专用，部分本地应用也会遵循；不遵循的应用可能直连。Claude Code 等命令行工具不一定使用系统代理，不能由「网页能用」推断它也能用。

浏览器 WebRTC / UDP 等连接可能不受系统代理控制，因此此场景不适合严格要求隐藏本地出口 IP 的用途。

## 4. 重点用 Claude / Claude Code，也看 YouTube、刷 TikTok；减少遗漏域名造成的出口分散

适合：更在意 Claude 及未列出的第三方公网请求都跟随 DC，接受国内公网连接也走代理。

- **订阅**：DC · 全公网代理
- **出站模式**：规则
- **系统代理**：开启
- **TUN**：开启
- **代理组**：出口选择 / AI / YouTube / TikTok → 自动回退；Claude → AI

Claude 命中专用规则后走 Claude → AI → 自动回退；未列出的普通公网域名走出口选择 → 自动回退。YouTube、TikTok 也通过同一台 DC 服务器。

配置处理的普通公网域名使用代理 DoH；本地 / Tailscale 解析和 DNS 引导仍有例外。此场景没有国内公网直连，不是「防封保证」；账号资格、地区和使用政策仍需符合服务要求。

## 代理组只要记住这些

- **自动回退**：优先 DC-Hy2，健康检查失败时尝试 DC-VLESS；不自动转 DIRECT，也不是自动选最低延迟。两种协议共用一台 DC 服务器，不能防服务器整体故障。
- **出口选择 / AI / YouTube / TikTok**：规则模式统一选择「自动回退」。**Claude**：选择「AI」。无需手动把自动回退固定为 Hy2。
- 每组保留一个选择是正常的；只有流量用到该组时才生效。收拢只是隐藏界面，不会停用，也不会造成重复代理。

## 必须知道的边界

- 系统代理 / TUN 决定连接怎样进入 Clash；规则 / 全局决定进入后怎样出站。两者不是一回事。
- 同一台服务器不等于已验证所有协议出口 IP 相同，也不代表住宅 IP；实际出口、IPv6、DNS 和 WebRTC 需要按设备核验。
- **四种场景都没有系统级断网保护（kill switch）**。Clash 退出 / 崩溃、TUN 关闭后可能恢复直连，不能保证零泄漏。
- 不公开订阅链接、节点密码，不上传到公共转换网站。手机小火箭的操作入口不同，见《小火箭使用指南》；不要照搬桌面 TUN 开关。
