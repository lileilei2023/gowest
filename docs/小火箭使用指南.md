# 小火箭使用指南：节点、配置与全局路由

gowest 0.5.7。适用 Shadowrocket，不是原版 Shadowsocks。
下面只以 DC 为例；安装器会根据服务器标签生成该用户自己的完整链接和说明，不要求同时拥有其他服务器。

## 先照这四步用

1. **导入节点**：首页 → ＋ → 类型 Subscribe → 粘贴节点订阅完整链接 → 保存。应有 `DC-Hy2`、`DC-VLESS`。
2. **导入配置**：底部“配置” → ＋ → 粘贴日常或全公网 `.conf` 完整链接 → 下载 → 点新文件 → 使用配置，确认有勾选。
3. **首页点 `DC-Hy2`**，全局路由选 **配置**，应用级“启用回退”保持关闭。
4. 打开连接。配置内 `出口选择 / AI / YouTube / TikTok → 自动回退`，`Claude → AI`，一般不用手调。

日常看 YouTube、刷 TikTok、用 Claude，国内保留直连：选 **DC 日常分流**。
希望未列出的普通公网域名也统一代理、接受国内公网也走代理：选 **DC 全公网代理**。
**这两份都用“配置”模式，不需要把全公网版改成“代理”模式。**

## 订阅链接后缀

所有客户端共用同一个基础链接 `/sub/<令牌>`，在末尾追加不同后缀得到不同内容：

| 追加后缀 | 内容 | 导入位置 |
| --- | --- | --- |
| （不追加） | 完整 Clash YAML，日常分流 | Clash Verge Rev / CMFA 订阅 |
| `-us` | 完整 Clash YAML，全公网代理 | 同上 |
| `-nodes` | Base64 原生 Hysteria2 / VLESS 节点列表 | 小火箭首页 → Subscribe |
| `-shadowrocket.conf` | 小火箭日常分流配置 | 小火箭“配置”页 |
| `-us-shadowrocket.conf` | 小火箭全公网配置 | 小火箭“配置”页 |

原生节点 URI 没有跨客户端统一的 Hy2 带宽字段；若导入后 Hy2 节点没有带宽目标，请在节点编辑页按服务器实际设置填写。

## 全局路由四种模式是什么

| 模式 | 谁决定出口 | 例子与注意事项 |
| --- | --- | --- |
| **配置** | 当前启用配置中的规则和代理分组 | 日常版让 YouTube / TikTok / Claude 走 DC、命中国内规则的连接直连；全公网版让其他普通公网也走 DC。推荐。 |
| **代理** | 首页当前选中的节点，或应用当前选中的分组 | 例如选 DC-Hy2，普通流量统一代理；不再按我们的域名规则做国内直连，不能指望专用 Claude 组照常决定出口。配置的 DNS 等设置仍可能生效。 |
| **直连** | 不经过代理节点 | 适合临时不用代理；不要把它当作保护本地出口的方式。 |
| **场景** | 按 Wi-Fi 名称 / 蜂窝 / 默认网络条件，自动选择预设路由模式、配置及节点或分组 | 例如家里 Wi-Fi 用日常配置，蜂窝用全公网配置。它是自动切换设置，不是识别 Claude 或 YouTube。没有明确需要时不用开启。 |

“代理”也不等于所有数据包无例外代理；系统限制、隧道排除地址和本地网络例外仍需考虑。四种模式都不是系统级断网保护。

## 首页节点和配置分组，不是一回事

首页列表是**节点库**，节点订阅导入成功不代表场景分流也导入成功。`default.conf` 若显示“代理分组 0”，就不是我们这份六组配置。

首页点 DC-Hy2 是明确选择一个同机默认节点，便于开始连接，也避免顶部显示与配置无关的名字。但本配置的规则显式引用分组，分组只含 `DC-Hy2 / DC-VLESS`：

- Claude → AI → 自动回退 → DC 节点。
- YouTube / TikTok → 自动回退 → DC 节点。
- 未分类公网 → 出口选择 → 自动回退；日常版的国内直连规则仍优先生效。

因此，首页点了 Hy2不会把配置内的回退锁死；首页点了另一来源节点，也不能把这些明确绑定的规则整体迁过去。想换服务器，要启用那台服务器的配套配置。

别的订阅留在首页、展开或收拢，都不会自动加入当前配置。我们的生成器不使用引用首页默认节点的 `PROXY` 兜底，也不用“全部订阅”的正则。若用户自己加了规则、改了分组、节点代理链或前置代理，行为需另行核对。

首页顶部节点名不是每条连接的路由证据；实际出站可在“数据 → 代理”日志里查看。测速和订阅刷新访问其他服务器也不等于业务流量通过它们转发。

## 两种“回退”分开看

- **配置内的“自动回退”**：一个 `fallback` 策略组，只含同机两协议。根据健康检查结果切换，故障发生到下一次测试之间可能有失败；不是最快线路选择，也不保证无缝切换。
- **全局路由页的“启用回退”**：应用级设置。其范围取决于命中的策略及简单模式设置；默认 `PROXY` 策略可能在首页其他节点中回退。为避免混用其他来源，本指南建议保持关闭，不靠它实现同机回退。

配置文件不能替用户确认 VPN 开关、全局路由、首页默认节点、场景或应用级回退开关。不要在 `.conf` 中虚构这些应用级字段。

## 安装器会给什么

新服务器完成一键部署后运行：

```sh
sudo bash /opt/la-vpn/deploy.sh urls --client shadowrocket
```

输出本服务器专属的三条完整链接及导入顺序，无需拼接：节点、日常配置、全公网配置。相同说明保存在 `/var/lib/la-vpn-deploy/generated/shadowrocket-import.txt`，仅 root 可读，不通过订阅 HTTP 服务公开。

二维码或跳转链接没有反应时，直接复制完整网址到上述入口；扫码支持因入口或版本而异，不作为必需路径。节点和配置升级时一起刷新，不手工改节点名。凭据不要发到公开聊天或第三方转换网站。

## 能力边界

小火箭使用原生 `.conf` 规则、代理组和代理 DNS；不会把 Clash 的 `GEOSITE`、`PROCESS-NAME`、`MATCH`、桌面 TUN 字段硬套进来。日常版国内分类使用 `GEOIP,CN`，与桌面的 GEOSITE + GEOIP 并非逐条等效。

不使用 MITM、脚本、URL 重写或全订阅正则；默认/备用 DNS 绑定同一服务器的具体节点，不支持的 UDP 不自动转直连。原生节点 URI 不保证携带 Hy2 带宽目标，必要时按实际套餐填写。

静态检查只检查生成内容，不代表已在每个 iOS / Shadowrocket 版本上实机验收。关闭连接、应用故障、系统例外、IPv6 / DNS / WebRTC 仍可能影响接管，不能保证零泄漏、住宅出口或账号安全。
